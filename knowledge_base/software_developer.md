# Role: Software Developer

## Core Competencies
- Programming Languages (Python, JavaScript, Java, C++)
- Data Structures and Algorithms (Arrays, Linked Lists, Trees, Graphs, Sorting, Searching)
- Object-Oriented Programming (Polymorphism, Inheritance, Encapsulation, Abstraction)
- Database Management Systems (SQL, Joins, Normalization, ACID properties)
- System Design (Client-Server architecture, REST APIs, Microservices, Load Balancing)
- Version Control (Git)

## Typical Interview Questions

### Technical
1. What is the difference between an abstract class and an interface?
2. Explain how a hash map works under the hood.
3. What is the difference between INNER JOIN and LEFT JOIN in SQL?
4. How do you handle exceptions in your preferred programming language?
5. Describe the principles of RESTful APIs.

### Scenario
1. You are tasked with designing a URL shortener. What components would you need?
2. Your application is experiencing slow database queries. How do you troubleshoot?

## Evaluation Rubric
- **Technical Accuracy:** Does the candidate provide correct and factual information?
- **Completeness:** Does the answer cover all edge cases or required parts?
- **Clarity:** Is the explanation easy to understand?
